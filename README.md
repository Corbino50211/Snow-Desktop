# Snow Desktop



The window-aware version is in **native/**. Download Mac and Windows builds from the [Native Snow Desktop workflow](https://github.com/Corbino50211/Snow-Desktop/actions/workflows/native.yml). See [installation, controls, attribution, and privacy details](native/README.md).

Includes snow on app windows and the Dock, cursor scattering, snow falling from moved/closed windows, and native tray/menu-bar controls. Based on MIT-licensed Snowhush. The Electron app at the repository root is the earlier prototype.
